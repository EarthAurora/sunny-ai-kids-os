# Level 2 Personal OS — evidence pack

This public folder is a sanitised submission and presentation pack for the Sunny AI for Kids education-centre pilot. It demonstrates a Level 2 Personal OS workflow without publishing the private Obsidian/MyBrain vault.

All data in this folder is fictional practice data. It does not contain real learners, families, staff contact details, credentials, or live operational records.

## What this demonstrates

- A private Personal OS structure: Inbox, notes, daily notes and review outputs.
- An Inbox-first workflow and review recommendations that do not alter source notes automatically.
- Daily, weekly and monthly review examples.
- A vault-health review covering links, frontmatter and orphan notes.
- A structured education-centre inventory data-cleaning workflow.

## Contents

- [`data-cleaning/sunny-level2-inventory-cleaning-practice.xlsx`](data-cleaning/sunny-level2-inventory-cleaning-practice.xlsx) — fictional raw, clean and rejected inventory rows, plus a category summary and chart.
- [`reviews/weekly-baseline.md`](reviews/weekly-baseline.md) — an evidence-based first weekly review.
- [`reviews/monthly-fictional-practice.md`](reviews/monthly-fictional-practice.md) — a clearly labelled fictional presentation-month review.
- [`reviews/vault-health-check.md`](reviews/vault-health-check.md) — a read-only vault health assessment.

## Inventory-cleaning result

The fictional workbook contains 126 raw rows, 113 clean rows and 13 rejected rows (including 6 duplicates). Cleaning standardises dates, supply categories, quantities and HKD unit costs; invalid or incomplete rows are retained in the rejected sheet with a reason.

## Privacy boundary

The complete MyBrain vault remains private. This evidence pack intentionally shows the workflow and fictional results only, while the public Sunny Operations OS remains a navigation and demonstration layer.
